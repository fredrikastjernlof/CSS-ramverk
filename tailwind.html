Tailwind CSS

Tailwind CSS är ett utility-first CSS-ramverk där designen byggs upp med små, återanvändbara CSS-klasser direkt i HTML. I stället för att erbjuda färdigstylade komponenter som knappar och kort ger Tailwind utvecklaren verktyg för att själv bestämma hur elementen ska se ut.

Ramverket innehåller ett stort antal klasser för bland annat färger, typografi, avstånd, Flexbox och Grid. Med responsiva prefix kan utseendet också anpassas efter olika skärmstorlekar direkt i HTML-koden.

Läs mer på Tailwinds officiella webbplats .

Fördelar och nackdelar

Fördelar

  • Stor designfrihet: Det går att styra nästan varje detalj i utseendet med hjälp av färdiga klasser, utan att behöva skriva egen CSS.
  • Flexibelt: Man är inte låst till färdigstylade komponenter utan kan bygga upp sin egen design från grunden.
  • Smidig responsivitet: Med prefix som md: och lg: går det att anpassa layouten till olika skärmstorlekar direkt i HTML.
  • Stor potential: När man väl lärt sig klasserna känns det som att det finns väldigt stora möjligheter att skapa precis det utseende man vill ha.

Nackdelar

  • Mycket att lära sig: Det stora antalet klasser gör ramverket ganska överväldigande i början.
  • Svårt att komma ihåg klasserna: Det krävs en del letande i dokumentationen innan man känner sig hemma i alla möjligheter.
  • Omfattande HTML: Eftersom varje detalj styrs med klasser kan elementen få väldigt långa class-attribut.
  • Inga färdigstylade komponenter: Till skillnad från exempelvis Bootstrap behöver man själv bygga upp utseendet på knappar, tabeller och andra komponenter.

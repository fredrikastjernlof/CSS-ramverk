Bootstrap

Bootstrap är ett CSS-ramverk med färdiga komponenter och klasser som är tänkt att göra det enklare att bygga responsiva webbplatser. Ramverket innehåller bland annat ett gridsystem, navigationsmenyer, knappar, formulär och kort som kan användas utan att man behöver skriva all CSS från grunden.

Bootstrap bygger på ett mobile first-tänk, där layouten anpassas efter olika skärmstorlekar med hjälp av brytpunkter och responsiva klasser.

Läs mer på Bootstraps officiella webbplats .

Fördelar och nackdelar

Fördelar

  • Smidigt gridsystem: Enkelt att skapa responsiva layouter med hjälp av rader, kolumner och brytpunkter.
  • Färdiga komponenter: Navigation, kort, tabeller och formulär går snabbt att bygga upp och får ett enhetligt utseende.
  • Många hjälpklasser: Det går att justera exempelvis marginaler, padding, färger och storlekar direkt i HTML.
  • Litet behov av anpassningar: De färdiga komponenterna fungerar bra tillsammans och kräver minimalt med egen CSS.

Nackdelar

  • Omfattande dokumentation: Det finns gott om information och exempel, men ibland krävs lite letande för att hitta det man söker.
  • Många klasser att lära sig: Det kan vara svårt att komma ihåg vilka klasser som finns och hur de ska kombineras, särskilt i början.

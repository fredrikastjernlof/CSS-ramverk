Publicering med Cloudflare Pages

För att få ut min laboration på nätet valde jag att testa Cloudflare Pages. Jag har tidigare publicerat webbplatser på lite olika sätt, bl.a studenter.miun.se, netlify, render och eget webbhotell, men Cloudflare är nytt för mig.

Om Cloudflare Pages

Cloudflare Pages är en tjänst för att publicera webbplatser, framför allt statiska sidor och frontend-projekt. Den kan kopplas till GitHub eller GitLab, så att webbplatsen byggs och uppdateras automatiskt när man skickar upp ändringar i sin kod.

Mer information finns i Cloudflares dokumentation .

Teknikstöd och kostnader

Cloudflare Pages fungerar med HTML, CSS och JavaScript och kan även användas med exempelvis React, Vue och Astro. För den som behöver köra kod på serversidan finns stöd för JavaScript och TypeScript genom Pages Functions.

Det finns en gratisnivå med upp till 500 byggen per månad, vilket är mer än tillräckligt för mitt lilla projekt. Det finns också begränsningar för bland annat filstorlek och antal filer, men inget som påverkade mig.

Publiceringen kostade mig alltså ingenting. Jag fick en adress som slutar på pages.dev, även om jag inte riktigt uppfattade om jag kunde påverka namnet själv. Det går också att koppla en egen domän om man vill.

Så gick publiceringen till

Jag började med att kontrollera att webbplatsen gick att bygga med Vite. Sedan skapade jag ett repository på GitHub och laddade upp projektet dit.

Därefter var det dags för Cloudflare. Jag loggade in med GitHub och kom igång direkt. Så långt var allt enkelt.

Sedan skulle jag bara hitta var man faktiskt publicerade en webbplats.

Det visade sig vara lättare sagt än gjort. Jag hamnade först under Workers och letade efter inställningar som inte fanns där. Till slut hittade jag länken till Pages, lite undangömd längre ner på sidan. Den hade gärna fått vara betydligt tydligare.

Men när jag väl kom rätt var det inga konstigheter. Jag valde mitt GitHub-repository, angav npm run build som byggkommando och dist som mapp för de färdiga filerna. Sedan tog Cloudflare hand om resten och webbplatsen var publicerad.

Fördelar och nackdelar

Fördelar

  • Gratisnivån räcker gott för mindre projekt.
  • Enkelt att koppla till GitHub.
  • Webbplatsen byggs och publiceras automatiskt.
  • Inga filer behöver laddas upp med FTP eller SFTP.
  • Stöd för flera olika frontend-tekniker.

Nackdelar

  • Jag tyckte att Pages var onödigt svårt att hitta.
  • Det var lätt att hamna under Workers av misstag.
  • Jag uppfattade inte om det gick att välja adressen själv.
  • Gratisnivån har vissa begränsningar, även om de inte påverkar mitt lilla projekt.

Min utvärdering

Bortsett från den lilla skattjakten efter Pages var det här faktiskt väldigt enkelt. Jag behövde inte hålla på med några krångliga inställningar och när jag väl hittade rätt fungerade publiceringen utan problem.

Så ja, Cloudflare Pages får absolut godkänt. Gränssnittet kunde ha varit lite tydligare, men själva publiceringen har jag inte mycket att klaga på.
